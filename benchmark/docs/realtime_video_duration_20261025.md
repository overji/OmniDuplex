# Realtime 模型按视频时长的表现

沿用三模型共同完成的2008条QA快照。按完整视频时长分组，不是问题后的剩余时长，也不是回复发生时间。区间均左开右闭，最后一组 >300秒。

时长来自 generation_context.duration_seconds；其中822个唯一视频与媒体缓存时长核对，0个无缓存，最大差异0.000000秒。

| 视频时长 | QA | 唯一视频 | 窗口 | MiniCPM R/P/F1 (%) | Gander R/P/F1 (%) | JoyAI R/P/F1 (%) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| ≤60秒 | 31 | 20 | 58 | 24.14 / 43.75 / 31.11 | 22.41 / 72.22 / 34.21 | 46.55 / 25.23 / 32.73 |
| 60–120秒 | 796 | 328 | 1620 | 28.83 / 32.39 / 30.50 | 15.31 / 46.97 / 23.09 | 25.49 / 13.61 / 17.75 |
| 120–180秒 | 476 | 208 | 1075 | 29.58 / 28.12 / 28.83 | 14.23 / 41.92 / 21.25 | 30.51 / 11.42 / 16.62 |
| 180–300秒 | 357 | 124 | 975 | 19.59 / 26.68 / 22.59 | 11.49 / 44.09 / 18.23 | 26.77 / 11.12 / 15.71 |
| >300秒 | 348 | 142 | 941 | 11.05 / 15.88 / 13.03 | 4.14 / 13.73 / 6.37 | 22.21 / 5.76 / 9.14 |

R=时间Recall，P=时间Precision。每组累计命中、窗口、输出后计算F1；仅评时间，未做内容judge。

注意：≤60秒组仅31条QA，结果波动可能较大。不同长度组的任务/模态构成不同，不能据此单独推断长上下文导致性能变化。MiniCPM/Gander输入音视频，JoyAI仅视觉。RTD/PR使用原运行，Agent使用最新task-text重评测。

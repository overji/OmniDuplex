\section{Experimental Results}

\subsection{Evaluation Protocol}

We evaluate response decisions with independent video-prefix probes and streaming response timing with realtime inference. Each reference response yields a negative prefix ending one second before the response window and a positive prefix ending at its end. Probe positive/negative accuracy measures whether a model speaks or remains silent; paired accuracy requires both decisions to be correct. Unparseable decisions count as incorrect; payload-format validity is reported separately and does not gate a positive decision. Missing inference records are reported as missing coverage. Realtime recall, precision and F1 use one-to-one onset matching within inclusive annotated windows; timing hits do not require correct content.

On 4,163 shared complete pairs (1,953 QA), Gemini-3.7-flash and Qwen3.8Omni achieve paired accuracies of 42.95\% and 27.38\%, respectively. MiniCPM and Qwen3 attain positive-prefix accuracies of 94.43\% and 91.86\%, with negative-prefix accuracies of 11.15\% and 14.87\%. These decision metrics do not establish whether generated response content is correct.

On the 2,008 shared realtime QA, MiniCPM achieves timing F1 of 25.31\%, compared with 18.47\% for Gander and 14.86\% for JoyAI. Gander has the highest timing precision (38.99\%) but lower recall (12.10\%). JoyAI has the highest recall (26.52\%), accompanied by 11,991 outputs and precision of 10.32\%. This illustrates why window recall should be interpreted together with output precision. JoyAI receives visual input only, so this table is not an input-matched audio-video comparison.

\subsection{Interpretation and Limitations}

The remote names Gemini-3.7-flash and Qwen3.8Omni were operator-confirmed. First-500 and remaining-1607 results were merged only after verifying split hashes, full-QA fingerprints, and every original pair ID against the annotated prefix windows. Canonical indices match the historical 2110-QA runtime; these exports contain the public 2107-QA set, excluding three missing-media records. Original predictions and text were preserved, with split IDs retained in provenance. Incomplete remote coverage remains missing; the main Probe panel uses only common completed pairs. Exact remote deployment IDs and inference configurations were not packaged with these files, so equal example identity does not establish identical prompts, sampling or token budgets. Shared coverage can omit difficult requests. Decision and timing scores do not measure content correctness. Agent format validity does not demonstrate successful execution; no tools or returned results are executed. The cancelled reference-history trial is excluded. No new model inference or paid judging was performed.

## 解释与限制

时间命中率 = 命中窗口 / 参考窗口；时间精度 = 命中窗口 / 预测输出数；F1 为两者调和平均。采用包含端点的一对一匹配，统计输出起始视频时间。

该结果表现为高召回、低精度：频繁发声容易覆盖窗口，但会产生大量窗口外或重复输出，不能仅依据命中率判断效果。

当前只有 timing 结果，没有 LLM judge 内容得分。Agent 的时间命中不要求调用合法，工具调用仅被记录且未实际执行；不能据此声称 Agent 任务成功率。

这是 95 条部分结果，不能视为全量 2,107 条评测；也不应直接与不同样本子集的其他模型阶段结果横向比较。

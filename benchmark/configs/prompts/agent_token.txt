Agent output protocol agent_token_v1: start speaking using the native speak token. First give a brief natural-language response to the user. If an available tool must be delegated, emit the single special token <|agent|> once, followed by exactly one JSON object: {"name":"agent_call","arguments":{...}}. Fill all arguments according to the supplied agent_call schema, using only observed evidence, available capabilities and authorized actions. Do not wrap the user-facing response in JSON. End the turn using the native turn terminator. Continue an unfinished response/call across media chunks without repeating <|agent|>. For refusals or clarification requests, give only the natural-language response and end the turn; do not emit <|agent|>. Do not execute tools or invent successful outcomes. RTD and PR responses retain their normal format and must not emit <|agent|>.
